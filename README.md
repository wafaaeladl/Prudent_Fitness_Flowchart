# Prudent Fitness Flowchart

## Project Overview
This project uses a flowchart to represent the process of developing a business plan for
Prudent Fitness, a welcoming and affordable gym.

## Files
- \Prudent-fitness-floechart.pdf` - The completed flowchart.
- Prudent_fitness.py - Python code demonstrating the decisions and actions in the flowchart.

## Standard Followed
I used standard flowchart conventions:
  - Ovals represent the start and the end.
  - Rectangles represent actions.
  - Diamonds represent decisions.
  - Arrows show the direction of the process.

## Python Implementation
The python program uses if, elif, and else statements to represent decisions
about community needs and the cost of opening the gym.

## Purpose
This project demonstrates how flowcharts can organize a process into steps and 
decisions and how the same logic can be represented in python.
